# Northlight Studio: test offer

Date: 2026-10-22. Written by Claude for plan phase 2 acceptance ("VoiceSync and one unrelated
offer both produce sensible packs").

Everything here is fictional: the studio, Sam Taylor, the address and the mailboxes. The domains
use the reserved `.example` TLD so nothing can ever be delivered. Its job is to prove that the
engine and the strategy pack work for a different country (UK, PECR), offer type (agency, one-off
price) and buyer (independent clinics) without code changes.

It was chosen in the design (brief §11 Q4, accepted on 2026-10-22 with the recommended defaults).
